# Rock Paper Scissors — JavaScript Project 🎮

## Project Overview

Rock Paper Scissors is an interactive browser-based game built using HTML and JavaScript.

I coded this project while following Ania Kubow's JavaScript tutorial, implementing three different versions of the classic Rock Paper Scissors game.

The project helped me strengthen my understanding of JavaScript fundamentals, browser interactions, and programming logic through hands-on practice.

## Technologies Used

- HTML5
- JavaScript
- DOM Manipulation

## Features

- Interactive Rock, Paper, and Scissors buttons
- Random computer-generated choices
- Automatic winner determination
- Real-time display of player and computer selections
- Three implementations of the game

## Skills Practiced

- JavaScript functions
- Conditional statements
- Event listeners
- DOM manipulation
- Random number generation
- Basic debugging and testing

## How to Run

1. Clone or download this repository.
2. Navigate to `rock-paper-scissors-examples`.
3. Open any of the three example folders.
4. Open `index.html` in your browser.
5. Select Rock, Paper, or Scissors to play.

Rather than only watching the tutorial, I actively wrote the code, followed the logic, tested the game, and practiced implementing the concepts.
